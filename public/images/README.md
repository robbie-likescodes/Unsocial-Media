# Prototype cover imagery

`covers.png` is an AI-generated six-panel photographic illustration created for this prototype. The UI displays individual panels using CSS background positioning. It does not depict actual users, venues, or events. Keep the original grid layout when replacing it, or update the Photo component to use independent images.

The rabbit icon in `public/rabbit.svg` is an original SVG illustration. Fonts are packaged locally via Fontsource; their licenses are included in their npm packages.
